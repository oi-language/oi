# Execution

Unavailable isolation fails pre-invocation `CONTEXT_ISOLATION_UNAVAILABLE`. Root TaskID/entry ActivationID are `root`/`root/a0`; loaded rules govern other IDs; probes use none.

## Canonical bytes

Strings are UTF-8. `nat` is `0` or unsigned decimal without leading zero; signed int is `0` or optional `-` plus nonzero-leading digits. SHA is lowercase 64-character ASCII hex. `frame(p)=UTF8(nat(byte-length(p)))+":"+p`; `record(tag,fields)=frame(tag)+frame(nat(field-count))+` each `frame(name)+frame(value)`; `sequence(tag,items)=frame(tag)+frame(nat(item-count))+` each `frame(item)`. No separators beyond frames; `empty` is zero bytes.

Manifest is record `manifest` fields `language,module,source-count,sources`: `Oi 0.0.2`, directive value, nat, and sequence `source-paths` of directive-ordered module-relative paths. Artifact is record `artifact` fields `role,path,bytes,characters,sha256`; role `execution|module|project|runtime|standard`, counts nat. Paths are normalized `/`-separated UTF-8 without `.`/`..`: installed-snapshot-relative for execution/runtime/std, `oi.mod` for module, module-relative for project. Sequence `artifacts` orders execution, module, closed project directives, triggered runtime rows, then std by path bytes, independent of reads. ManifestDigest/SourceDigest are lowercase SHA-256 of these bytes; receipts retain records.

Module identity is record `module` field `name` from directive. Entry is record `entry` fields `name,path,line,column` from token; path is normalized module-relative, positions one-based nat.

Type is record `type` fields `kind,args`, args sequence `type-args`. `bool|int|text|unit|failure` have none. `optional|slice|set|task|outcome|channel|sender|receiver` has component type; `map` key,value types; `struct` ordered record `field` fields `name,type`; `enum` ordered record `member` fields `name,ordinal`; `named` record `identity` fields `module,path,name`, then underlying type. Identity strings are normalized UTF-8; ordinal nat.

Value is record `value` fields `type,body`; nested value means full record. Body tag(fields): `bool(value=0|1)`; `int(value=signed-int)`; `text(value=UTF8)`; `unit()`; `enum(ordinal=nat)`; `named(value)`; `optional(present=0|1,value=empty-or-value)`; `struct(fields=` sequence `field-values` of record `field-value(name,value)`); `slice(values=` sequence `values`); `map(entries=` key-ordered sequence of record `entry(key,value)`); `set(values=` element-ordered sequence); `handle(kind,id)`; `outcome(state,value,failure)`, state `completed|failed|cancelled`, latter optional; `failure(category,phase,location,detail,trace)`, trace source-ordered UTF-8 sequence. Digest is lowercase SHA-256 of the record. Host secret is record `secret` fields `type,digest`, not an Oi value; raw bytes excluded.

Inputs is sequence `inputs` of declaration-ordered record `input(position,name,type,value)`, position nat. Mappings is sequence `mappings` of source-ordered record `mapping(effect,signature,authorities,host-mapping)`; identities UTF-8, signature type identity. Authorities is sequence `authorities` of byte-sorted record `authority(name)`. Policy is record `policy(mode,limits)`; mode `direct|durable|resume|debug|replay`, limits sequence `limits` of supplied record `limit(name,value)` in order `max-concurrency,max-depth,max-detached-tasks,max-channel-capacity`, value nat; omitted limits have no item. Empty containers retain tags/counts. Digest is lowercase SHA-256 of complete bytes.

Operations is sequence `operations` of journal-ordered record `operation(id,kind,location,input-digest,state,result)`; result optional value/failure/UTF-8 ID/outcome. Budgets is sequence `budgets` of name-byte-ordered record `budget(name,actual,limit)`, nats. Names: `adapter|spec|prefix|prefix+adapter|shard:<snapshot-path>|source:<module-path>|graph|line:<module-path>`; evaluated counters occur. Prefix ends before first `## core language`; line actual is maximum decoded line characters. Terminal is record `terminal(state,failure)`; state `Completed|Failed|Indeterminate|Cancelled`, failure optional canonical failure value.

## Reply and receipt

After recognition each terminal returns record `receipt` fields `snapshot,module,entry,manifest,manifest-digest,artifacts,source-digest,inputs,inputs-digest,mappings,mappings-digest,authorities,authorities-digest,policy,policy-digest,operations,reply,terminal,budgets,load-failure`; snapshot is UTF-8 `Oi 0.0.2`, never optional; bootstrap failure returns none. Record `optional` fields `present,value`; absent=`0,empty`, present=`1,canonical-bytes`. On pre-entry module/source failure, module and manifest/digest are present iff parsed/valid; entry, inputs/mappings/authorities/policy and their digests, and reply are absent; artifacts, SourceDigest, empty operations, terminal, evaluated budgets, and load-failure are present. Failed artifact is omitted; load-failure is record `load-failure` fields `role,path,category`. Invocation count is zero.
