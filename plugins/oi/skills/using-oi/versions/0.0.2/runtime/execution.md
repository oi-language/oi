# Execution

UTF-8; `nat=0|[1-9][0-9]*`; `signed=0|-?[1-9][0-9]*`; SHA=64 lowercase hex. `frame(p)=UTF8(nat(byte-length(p)))+":"+p`; `record(t,f)=frame(t)+frame(nat(field-count))+` each `frame(name)+frame(value)`; `sequence(t,i)=frame(t)+frame(nat(item-count))+` each `frame(item)`. Empty=zero bytes; frames delimit. `R t(a,b)`=field order; `S t[...]`=sequence. `O(x)=R optional(present,value)`: absent=`0,empty`, present=`1,x`.

Manifest=`R manifest(language,module,source-count,sources)`: `Oi 0.0.2`, directive, nat, ordered module-relative `S source-paths[...]`. Artifact=`R artifact(role,path,bytes,characters,sha256)`, role=`execution|module|project|runtime|standard`, counts nat. `/` UTF-8 paths are normalized: snapshot-relative execution/runtime/std, module `oi.mod`, module-relative project; no `.`/`..`. Artifact S=execution, module, project directives, runtime rows, std path bytes. ManifestDigest/SourceDigest=lowercase SHA-256; receipt retains records. Module=`R module(name)`; entry=`R entry(name,path,line,column)`, module-relative one-based nats.

Type=`R type(kind,args)`, args=`S type-args[...]`. `bool|int|text|unit|failure` none; `optional|slice|set|task|outcome|channel|sender|receiver` component; `map` key,value; `struct` ordered `R field(name,type)`; `enum` ordered `R member(name,ordinal)`; `named` has `R identity(module,path,name)`, underlying type. Identities normalized UTF-8; ordinal nat.

Value=`R value(type,body)`; nested=full Value. Body R: `bool(value=0|1)`; `int(value=signed)`; `text(value=UTF8)`; `unit()`; `enum(ordinal=nat)`; `named(value=Value)`; `optional(present,value)=O(Value)`; `struct(fields=S field-values[R field-value(name,value)])`; `slice(values=S slice-values[Value])`; `map(entries=S map-entries[R entry(key,value)])` key order; `set(values=S set-values[Value])` element order; `handle(kind,id)`; `outcome(state,value,failure)` with O(Value): completed=present/absent, failed=absent/present, cancelled=absent/absent; `failure(category,phase,location,detail,trace)`, trace=source-ordered `S trace[UTF8]`. Digest=lowercase SHA-256. Host secret=`R secret(type,digest)`, not Oi; raw bytes excluded.

Inputs=`S inputs[R input(position,name,type,value)]` declaration order; position nat. Authorities=byte-sorted `S authorities[R authority(name)]`. Effect=`R effect(module,path,name)`, normalized. Signature=`R signature(parameters,result)`: ordered `S parameters[R parameter(position,name,type)]`, Type result; omitted=unit. Mappings=source-order `S mappings[R mapping(effect,signature,authorities,host-mapping)]`. Policy=`R policy(mode,limits)`; mode=`direct|durable|resume|debug|replay`; limits=`S limits[R limit(name,value)]`, names ordered `max-concurrency,max-depth,max-detached-tasks,max-channel-capacity`, values nat, omissions absent. Empty retains tags/counts. Digest=lowercase SHA-256 of all bytes.

Operations=`S operations[R operation(id,kind,location,input-digest,state,result)]`; journal order. Input-digest=SHA-256(`R operation-input(kind,payload)`); derive payload=`R derive-input(target,interpolations)` with Type and source-ordered `S interpolations[Value]`. Result=`R operation-result(kind,value)`: `none` empty, `value` Value, `failure` failure Value, `id` stable UTF-8 ID, `outcome` outcome Value. Budgets=name-byte-ordered `S budgets[R budget(name,actual,limit)]`, nats; names `adapter|spec|prefix|prefix+adapter|shard:<snapshot-path>|source:<module-path>|graph|line:<module-path>`. Prefix ends before `## core language`; line=max characters. Terminal=`R terminal(state,failure)`, state=`Completed|Failed|Stopped`, failure=O(failure Value): Completed absent; Failed/Stopped exact present. Root-ending Failed/Indeterminate/Cancelled operation maps to Failed. Stopped only means explicit post-admission controller termination without program failure or causal terminal operation; direct program execution never Stopped.

Receipt=`R receipt(snapshot,module,entry,manifest,manifest-digest,artifacts,source-digest,inputs,inputs-digest,mappings,mappings-digest,authorities,authorities-digest,policy,policy-digest,operations,reply,terminal,budgets,load-failure)`; absent pre-recognition. Required: `Oi 0.0.2` snapshot, artifacts, source-digest, operations, terminal, budgets. Optional: module, entry, manifest/-digest, inputs/-digest, mappings/-digest, authorities/-digest, policy/-digest, reply, load-failure; pairs co-present. Gates: module=parse; manifest=validation; entry=static; mappings+authorities=effect mapping; inputs=binding; policy=admission; reply=landing; load-failure=module/source/artifact. Completed has all phases, reply iff landed, no load-failure. Pre-entry load failure has completed phases+required+load-failure, no entry/later/reply/failed artifact, zero calls. Load-failure=`R load-failure(role,path,category)`.
